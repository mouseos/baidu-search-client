## 2. 残る技術的課題

1. **ant_ct の時刻近似**: `DateTimeUtil.getCalibratedTime()` の校正
   オフセット `mDelta` は Python から観測できないため 0 とする近似
   （時刻自体は秒単位で正確）。実測ではこの近似で検索が成功して
   いるが、サーバ側の受理条件の保証はない。
2. **再現範囲の限定**: URL 生成は静的解析で確定した範囲のみ。
   端末由来パラメータ（cuid 等）は付けないため、実機リクエストとの
   完全一致は保証しない。これは仕様であり、捏造で埋めることはしない。
3. **HTML 構造への依存**: パーサーは実測時点（2026-10）の DOM 構造に
   基づく。未知の tpl は unknown として記録される設計だが、Baidu 側の
   構造変更時は抽出ルールの更新が必要。
4. **広告の実 HTML 未検証**: 実測ページに広告結果が存在しなかった
   ため、広告分類は合成フィクスチャでの検証まで（第16ラウンドからの
   制限を継承）。
5. **リダイレクトの段階別制御**: 現行は到達先ホストの検証であり、
   中間ホストへのリクエスト発行自体は requests に委ねている
   （security-review.md §1 の注記）。
6. **対応環境**: 検証は Linux / Python 3.12 のみ。宣言は >=3.10
   だが、3.10 / 3.11 / 他 OS での実測はしていない。
7. **配布物の署名・再現可能ビルド**: wheel のバイト再現性
   （タイムスタンプ等）は未保証。sdist 再ビルドではコード内容の
   一致までを確認した。

## 3. ライセンス・出所に関する確認事項（再配布前に要確認）

- **出所**: 本パッケージは、Baidu 公式 Android アプリ
  （com.baidu.searchbox 15.57.1.10）を第三者が静的解析して得た
  仕様の再現実装である。Baidu 公式の API・SDK ではなく、Baidu の
  許諾を得たものでもない。README 等で公式と誤認させる表現は
  していない。
- **APK 由来の固定値**: ant_ct の鍵・IV は APK のネイティブ
  ライブラリ内に含まれていた固定リテラルに由来する
  （`baidu_search/antct.py` に来歴を明記）。これらを含むコードの
  再配布が Baidu の知的財産権・利用規約に抵触しないかは、
  公開前に権利面の確認が必要である。
- **APK 本体・逆コンパイル結果は配布物に含めていない**
  （package-build-report.md §4 のスキャンで確認）。
- **サービス利用規約**: 本クライアントは Baidu の検索サービスへ
  アプリの経路を模したリクエストを送る。再配布・公開運用の前に、
  対象サービスの利用規約（自動アクセスに関する条項を含む）との
  整合を確認すること。本ラウンドでは匿名の通常検索を最小限の
  回数だけ実測し、制限応答時は停止する運用を維持した。
- **本パッケージ自体のライセンス**: 現在は pyproject に
  `Private research code` と記載した私的研究コードであり、
  オープンソースライセンスは付与していない。再配布する場合は
  ライセンスの選定と、上記の出所表示の維持が必要。
- **商標**: 「Baidu」は Baidu, Inc. の商標である。パッケージ名・
  説明文は事実関係の記述（解析対象の明示）に留めている。
